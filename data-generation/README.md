## Aqui se encuentra los archivos del codigo generador de datos Dummy

Aqui se guarda los archivos tanto del generador hecho en python, como el DDL de la base de datos generado con el software de oracle sql developer data modeler.

## Para usar el generador no es necesario tener la carpeta "db". El archivo de esa carpeta (un .sql), se puede ejecutar en el oracle sql developer para comprobar la veracidad de la base de datos. Luego de eso puede usar los archivos de la carpeta src (teniendo las librerias de requirements.txt descargadas en python) y ejecutar el archivo de inserciones.py
